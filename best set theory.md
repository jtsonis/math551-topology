# Set Theory for Topology

## Results

Proofs are below.

Let $f\colon X\rightarrow Y$, $A \subseteq X$, $B \subseteq Y$.
* [1] $f(f^{-1}(B)) \subseteq B$; there is equality iff $f$ is injective.
* [2] $A \subseteq f^{-1}(f(A))$; there is equality iff $f$ is surjective.
